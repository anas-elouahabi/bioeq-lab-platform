# BIOEQ LAB 4.0 - Plateforme Pharmacocinetique & Integrite des Donnees (ALCOA+)

[![Regulatory Standards](https://img.shields.io/badge/Compliance-FDA%20%7C%20EMA%20%7C%20ALCOA%2B-red.svg)](https://www.fda.gov/)
[![Technical Report PDF](https://img.shields.io/badge/Documentation-White%20Paper%20PDF-blue.svg)](Rapport_Technique_BIOEQ_LAB_4_0.pdf)

Plateforme d'analyse pharmacocinetique non-compartimentale (NCA), de simulation de puissance statistique (PowerTOST) et d'evaluation de bioequivalence conforme aux referentiels reglementaires internationaux (FDA / EMA) et aux standards d'integrite de donnees ALCOA+.

Projet d'ingenierie developpe dans le cadre des activites de biometrie clinique et hospitaliere.

---

## 1. Documentation Technique & Methodologique

Le rapport d'ingenierie complet, anonymise et formalise selon les standards reglementaires, est directement consultable :
* Rapport complet au format PDF : [Consulter le Rapport Technique (PDF)](Rapport_Technique_BIOEQ_LAB_4_0.pdf)

Le document detaille :
* La formulation mathematique de l'analyse non-compartimentale (methodes trapezoidales lineaire/log, cinetique d'elimination terminale).
* L'inference statistique de bioequivalence moyenne (ANOVA sur modele mixte 2x2, procedure TOST, intervalle de confiance a 90%).
* Le dimensionnement clinique et la simulation de puissance face a la variabilite intra-sujet (PowerTOST).
* L'architecture bimodulaire (moteur R / interface Python) et la securisation des flux selon les principes ALCOA+ (empreintes cryptographiques SHA-256).
